Politique de Confidentialité - ConvertUltra
Dernière mise à jour : 14 mai 2026

1. Collecte de données

L'application ConvertUltra ne collecte aucune donnée personnelle. Le traitement des fichiers vidéo et audio est effectué localement sur votre appareil.

2. Intelligence Artificielle

L'application utilise l'API d'Anthropic (Claude) via votre propre clé API. Les requêtes sont envoyées directement aux serveurs d'Anthropic sans aucune interception de notre part.

3. Contact & Assistance

Pour toute question ou problème technique, vous pouvez ouvrir une "Issue" sur ce dépôt GitHub ou nous contacter via l'onglet support.
3. Enregistrer (Commit)

Descends en bas de la page.

Dans le champ "Commit message", écris : Ajout de la politique de confidentialité.

Clique sur le bouton vert "Commit changes".

4. Activer le lien public (GitHub Pages)

C'est l'étape cruciale pour avoir une URL à donner à Apple :

En haut de ton dépôt, clique sur l'onglet Settings (Paramètres).

Dans le menu de gauche, clique sur Pages.

Sous "Build and deployment", vérifie que la source est bien "Deploy from a branch".

Sous "Branch", sélectionne main (ou master) et clique sur Save.

Attends 1 minute. Un bandeau apparaîtra en haut avec ton URL : https://ton-pseudo.github.io/ConvertAISimple/.
